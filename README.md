# Galaxy S24 FE Handbuch

Interaktives, inoffizielles Einsteiger-Handbuch für das Samsung Galaxy S24 FE (Deutsch).

**Öffnen:** `index.html` im Browser öffnen (am PC oder Smartphone). Keine Installation nötig.

## Inhalt
12 Kapitel: Gerät kennenlernen, Einrichtung, Grundbedienung, Sicherheit, Kamera, Galaxy AI,
Akku, Anpassen & Barrierefreiheit, Verbindungen, Apps & Speicher, Problemlösung, Wissenstest/FAQ/Glossar.

Interaktiv: Schritt-Assistenten mit Bildschirm-Illustrationen, klickbares Geräte-Modell,
Tastenkombinations-Simulator, animierte Gesten, Hilfe-Assistent, Quiz, Volltextsuche,
Fortschritt, Glossar-Popups, Hell/Dunkel und Schriftgröße.

## Bearbeiten
Quelltexte liegen in `src/` (`content.html`, `styles.css`, `mocks.js`, `data.js`, `app.js`, `shell.html`).
Nach Änderungen neu bauen:

```
python3 build.py
```
